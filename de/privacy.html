DIE APP — WELCHE DATEN WIR ERHEBEN

Wir erheben keine personenbezogenen Daten.

BudgetBear ist so konzipiert, dass die App vollständig auf deinem Gerät funktioniert, ohne dass eine Erhebung personenbezogener Daten, ein Konto oder ein Server erforderlich ist. Es gibt keinerlei Synchronisation — deine Daten verlassen niemals dein Gerät. Deine Vorhaben, Sparziele, Zahlungsinformationen und App-Einstellungen gehören ganz allein dir.

Lokal gespeicherte Daten:

  • Vorhaben-Daten: Alle von dir erstellten Vorhaben, Sparziele, Zahlungsinformationen und damit zusammenhängende Daten werden lokal auf deinem Gerät gespeichert.
  • App-Einstellungen: Alle App-Einstellungen werden lokal auf deinem Gerät gespeichert.

DIE WEBSITE — WELCHE DATEN WIR ERHEBEN

Diese Website wird auf GitHub Pages gehostet und besteht aus einer Handvoll statischer HTML-Seiten und Stylesheets — es gibt weder eine Datenbank noch serverseitigen Code noch Benutzerkonten jeglicher Art. Wir verwenden keine Cookies, Tracker oder Analysetools. Wir erheben keine personenbezogenen Daten von Besuchern.

Wie bei jedem Webserver zeichnet GitHub Pages beim Besuch dieser Website automatisch grundlegende Server-Logs auf. Diese Protokolle können deine IP-Adresse, den Browsertyp, die verweisende Seite sowie das Datum und die Uhrzeit deines Besuchs enthalten. Diese Daten werden von GitHub gemäß deren Datenschutzerklärung aufbewahrt. Wir haben keinen Zugriff auf individuelle Besucherprotokolle und nutzen diese Daten weder für Tracking noch für Profiling.

WEITERGABE UND OFFENLEGUNG VON DATEN

Wir teilen, verkaufen oder analysieren deine Daten nicht.

Da alle App-Daten auf deinem Gerät verbleiben und wir keine personenbezogenen Daten erheben, werden keine Daten an Dritte, Werbenetzwerke oder Analyseanbieter weitergegeben.

DATENSICHERHEIT & SPEICHERDAUER

Deine Vorhaben-Daten und App-Einstellungen werden mithilfe von Standard-Sicherheitsmaßnahmen von iOS, iPadOS und macOS sicher auf deinem Gerät gespeichert. Die Daten verbleiben auf deinem Gerät, bis du die App löschst oder die Inhalte manuell entfernst.
